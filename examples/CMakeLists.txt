# OptiWeave Examples
#
# Note: Examples are not built by default. They are meant to be transformed
# and compiled using the optiweave tool itself.
#
# To use an example:
#   ./build/optiweave examples/basic_transformation/example.cpp --compile -o example
#
# Examples included:
# - basic_transformation/example.cpp - Basic array access transformation
# - overflow_test.cpp - Integer overflow detection test
# - fp_precision_test.cpp - Floating-point precision warnings test
# - test_memory_profiling.cpp - Memory profiling test
# - test_cache_profiling.cpp - Cache profiling test (Linux only)
# - test_dataflow.cpp - Data flow analysis test
# - test_callgraph.cpp - Call graph generation test
# - test_dependencies/ - Dependency graph analysis test
