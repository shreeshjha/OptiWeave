When to Use What recommendations

Goal Best Tool Why
Find CPU bottleneck function gprof  /  OptiWeave gprof for quick sampling; OptiWeave for exact counts + operation breakdown
Find memory access patterns OptiWeave Subscript counting + hotspot tracking pinpoint array access bottlenecks
Find op-type bottleneck (mul vs div vs sub) OptiWeave only No other tool distinguishes between operation types
Find memory safety bugs ASan  +  Valgrind Purpose-built for buffer overflows, use-after-free, etc.
Profile in CI / containers OptiWeave No kernel privileges needed; works in sandboxed environments
Profile production binary (no rebuild) perf  /  Valgrind Attach to running process without source transformation
Auto-fix detected issues in source OptiWeave only --auto-patch for perf, --auto-fix for correctness — no other tool rewrites source
Static code quality analysis OptiWeave Complexity, data flow, FP precision, overflow — all in one tool
